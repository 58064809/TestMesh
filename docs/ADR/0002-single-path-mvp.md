# ADR 0002：Single-path MVP

- **状态**：已接受
- **日期**：2026-09-01

## 背景

MVP 同时维护多条实现路径会增加测试矩阵、模糊故障边界并推动过度开发。

## 决策

每个阶段、每项能力只允许一条实现路径。不得维护主方案/降级方案/兼容方案/备用实现。

P01 唯一路径为：Refine + Ant Design UI → TestMesh Node 服务 → OpenAI Responses API → 单一 OpenAI 多模态模型。

## 影响

- 方案失败时不能自动切换模型、接口、解析器或本地生成逻辑。
- 新路径必须作为路线变更报告并等待用户批准。
