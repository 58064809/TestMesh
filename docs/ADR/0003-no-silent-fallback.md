# ADR 0003：No silent fallback

- **状态**：已接受
- **日期**：2026-09-01

## 背景

测试与质量平台的可信度依赖真实状态和可追溯证据。静默降级、mock 顶替或伪造证据会让用户误判结果。

## 决策

既定方案失败时必须停止在失败点，明确报告：

1. 失败原因；
2. 对当前验收的影响；
3. 可选方案；
4. 推荐方案。

未经用户明确批准，不得降级、替换、mock 顶替、自动重试、增加 fallback 或保留第二套实现。

## 影响

- API、模型、文件格式或 Evidence 校验失败时，P01 返回显式错误。
- 无法可靠定位页/段/图片时，结果必须标记“定位受限”，不能省略证据或猜测位置。
