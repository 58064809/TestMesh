# H00：Harness Foundation

- **状态**：已完成
- **授权日期**：2026-09-17
- **完成日期**：2026-09-17
- **目标**：在继续需求分析、测试设计和自动化之前，建立由 Harness 控制上下文装配、能力暴露、状态恢复和完成判定的统一基础。

## 范围

- 集成 LangGraph 作为唯一 Workflow/Harness Runtime。
- 在同一 LangGraph 体系内评估并接入 Deep Agents / LangChain Agent 能力。
- 定义 Stage Profile、Task Manifest、Artifact Envelope 和 Completion Report 的固定协议。
- 定义 Context、Knowledge、Skills、Tools、Policy、Schema 六类装配边界。
- 建立暂停、恢复、失败、取消和完成状态语义。
- 建立业务数据与 Checkpoint 的职责边界。
- 保存运行所用 Profile、Schema、Skill 和 Policy 版本。
- 建立最小可观察运行记录；不自研 Trace/Eval 平台。

## 明确不做

- 本阶段不重新发送真实 PRD 模型请求。
- 不生成测试用例，不生成自动化代码，不执行 API/UI 自动化。
- 不接入 RAG，不建设向量检索基础设施。
- 不删除仍可作为 RA01 输入的原始需求资料；不为旧协议建设永久兼容层。
- 不实现 APP、性能或安全测试的新能力。
- 不实现 Failure Triage；只为后续阶段保留标准 Artifact 接口。

## 单一路径

```text
Task Manifest
  → Stage Profile 选择
  → Harness 装配 Context / Knowledge / Skills / Tools / Policy / Schema
  → LangGraph 执行与 Checkpoint
  → 确定性 Completion Gate
  → Artifact 或显式失败/等待人工输入
```

## 验收标准

1. 存在一份已接受 ADR，明确框架选择、职责边界和迁移策略。
2. 任务协议能固定表达阶段、输入引用、允许能力、版本和状态，不以自由文本替代关键字段。
3. 至少一条不调用付费模型的测试图证明：Harness 能装配阶段配置、暂停/恢复，并拒绝未经完成条件验证的“已完成”。
4. Checkpoint 与业务 Artifact 分离；Checkpoint 只保存状态和对象引用。
5. 未暴露给阶段的 Skill、Tool 或 Source 不能被 Agent 使用。
6. 失败停在真实节点，页面或 API 能得到明确失败阶段和原因，不存在静默降级。
7. lint、测试和 build 全部通过。

## 当前环境事实

- 仓库为 Node.js/TypeScript。
- 当前旧业务数据仍使用 SQLite，RA01 负责一次性迁移或清理后切换到 PostgreSQL，不保留双实现。
- 本机 PostgreSQL 17.6 服务运行于 `127.0.0.1:5432`；`psql` 未加入 PATH 不代表未安装。
- H00 使用本机 `testmesh` 数据库，不使用 Docker PostgreSQL；密码只从 `PG_LOCAL_PASSWORD` 读取。
- LangGraph Checkpoint 使用 `harness_checkpoint` Schema，TestMesh 运行摘要使用 `harness_runtime` Schema。
- `MemorySaver` 只用于无业务数据的单元测试，不是生产持久化路径。

## 实现与验收记录

- LangGraph 是唯一 Workflow Runtime，已验证图执行、Interrupt、同一 Checkpoint 恢复和确定性 Completion Gate。
- LangChain `createAgent` 是阶段 Agent Loop；Deep Agents 的 Skills/Filesystem Middleware 负责渐进式 Skill 加载。H00 未启用异步子 Agent、Interpreter、Shell 或写文件能力。
- 固定协议已覆盖 Task Manifest、Stage Profile、Artifact Envelope、Completion Report 以及 Context、Knowledge、Skills、Tools、Policy、Schema 六类装配项。
- 未声明的 Skill 和 Tool 不进入 Agent；无证据时，即使 Agent 自报完成也会被 Completion Gate 拒绝。
- 官方 `PostgresSaver` 已完成真实中断恢复验收。验收运行 `h00-pg-99e55982-f623-46ea-aed7-dc6538089e42` 在关闭连接后使用新连接恢复并完成。
- 可观察性直接消费 LangGraph `tasks/tools` 流，只保存节点、工具、状态和失败位置摘要；不复制节点输入输出，不自研 Trace 平台。计划内失败已准确记录在 `planned_failure`。
- 自动验收结果：48 项测试通过，lint 通过，客户端与服务端 build 通过，PostgreSQL 集成验收通过。
