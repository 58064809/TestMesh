# P01：统一工作台与 PRD 多模态需求分析

- **状态**：已完成（2026-09-01）
- **目标**：交付统一中文工作台中的最小多模态需求分析闭环。

## 范围

- Refine + Ant Design 企业后台式 Shell。
- AI Chat 薄 UI，支持文本、图片和文件上传。
- Chat Attachment 与 Project Knowledge 两类入口及最小文件清单。
- 服务端直连 OpenAI Responses API。
- 结构化需求、风险、待确认问题、证据。
- 证据关联来源文件，并在可靠时提供页码、段落或图片定位。

## 验收标准

1. 用户进入统一中文工作台并打开 AI Chat。
2. 用户上传 PRD，可附带图片或截图。
3. 用户输入“帮我分析这个需求”。
4. OpenAI 多模态模型完成分析。
5. 工作台展示结构化需求、风险、待确认问题和证据。
6. 证据关联真实来源；无法可靠定位时显式显示限制。
7. lint、测试和 production build 全部通过，并完成一次受控真实 API 验收。

## 明确不做

- UI 自动化、API 测试执行、APP、性能、安全测试。
- OpenHands、Open WebUI、Langflow、Temporal、Keploy。
- Playwright、Appium、k6、ZAP。
- 向量库、复杂知识库、长流程编排、后台任务。
- 自动重试、模型切换、mock 分析或任何 silent fallback。

## 依赖

- Node.js 24+
- Refine、Ant Design、OpenAI 官方 Node SDK
- 服务端环境变量 `OPENAI_API_KEY`
- 单一模型 `gpt-5.6-luna`
- 单次请求理论 token 费用上限低于 0.50 美元

## 下一阶段入口

仅在全部验收通过、Roadmap 将 P01 标记为已完成且用户明确批准后进入 P02。
