# P02：领域模型与 OpenAPI 测试闭环

- **状态**：已完成（2026-09-01）
- **目标**：建立 Requirement/Risk/Evidence/TestCase 数据模型，完成 OpenAPI → Schemathesis → TestRun 闭环。

## 范围

- 领域模型与持久化。
- OpenAPI 导入。
- Schemathesis 4.24.3 单一 Runner，通过 `uvx` 执行。
- TestRun 结果及 Evidence 关联。
- TestCase 表示 OpenAPI operation 的测试定义/Test Intent；generated examples 仅属于 TestRun。
- 最小 Header/Auth 输入；凭据只用于本次运行，不持久化。

## 验收标准

导入 OpenAPI 后可生成、运行并查看 Schemathesis 测试，结果可追溯到需求、用例和证据。

## 明确不做

UI/APP/性能/安全测试、OpenHands、备用 API Runner、第二种报告格式、Python SDK、数据库抽象、环境管理系统、Credential Vault、通用 Runner Framework。

## 依赖

P01 已完成；数据模型和 Schemathesis 集成方案已批准并记录在 ADR 0004。

## 下一阶段入口

P02 全部验收通过并获用户批准后进入 P03。

## 验收记录

- 使用有效 OpenAPI 3.0.3 fixture 导入 1 条 `GET /items/{itemId}` operation，并生成 1 条 TestCase 定义。
- Requirement、Evidence、TestCase 与 TestRun 通过 SQLite 持久化并建立追溯关系。
- 通过 `uvx schemathesis@4.24.3` 对本地真实 HTTP 服务执行；固定单 worker、deterministic、zero retry。
- 受控目标返回 500，Schemathesis 生成 2 个 examples；TestRun 保存 2 个失败项。
- 失败项包含 operation、checks、request、response、reproduction，并正确关联 TestCase。
- 结果只使用 JUnit 和同一 Runner 进程的脱敏输出；未引入第二种报告格式、Python SDK、备用 Runner 或 fallback。
- lint、9 项测试和 production build 全部通过；API 测试页面完成视觉核对。
- P03 未开始；进入 P03 仍需用户明确批准。
