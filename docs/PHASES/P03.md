## 固定实现路径

- Agent Server：`ghcr.io/openhands/agent-server:1.44.0-python`。
- Client：`@openhands/typescript-client@1.39.0`。
- 每个任务使用一个一次性 Docker 容器，仅监听 `127.0.0.1`，仅将用户选择的仓库挂载到 `/workspace`，不挂载 Docker Socket。
- Agent 使用 OpenHands 注册工具 `terminal` 和 `file_editor`；不自研 Agent Loop 或迭代控制器。
- 设置 `NeverConfirm`，API retry 为 0，TestMesh 单 worker，用户可手动停止。
- Agent Event 在任务结束后通过客户端 `conversation.state.events.getEvents()` 单一路径读取，不使用 WebSocket 兼容层或手写 REST。
- 只从 `tool_name=terminal` 的 `ObservationEvent` 提取命令、`observation.content[].text` 和退出码；完整事件 payload 脱敏后持久化。
