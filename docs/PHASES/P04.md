## P04-B：Android Emulator + Appium 固定路径

- 仅支持本机已启动的 Android Emulator；不支持真机、iOS、设备农场、云设备或设备 fallback。
- 固定 Appium Server `3.7.0` 与 UiAutomator2 Driver `8.5.2`，服务仅监听 `127.0.0.1:4723`。
- 目标测试项目固定使用 WebdriverIO `9.31.5`、`@wdio/cli` `9.31.5`、`@wdio/local-runner` `9.31.5`、`@wdio/mocha-framework` `9.31.5` 与 `@wdio/junit-reporter` `9.31.2`；声明或安装版本不匹配立即停止。
- TestMesh 在运行前要求且只允许一个状态为 `device`、序列号为 `emulator-*`、`sys.boot_completed=1` 的设备；物理设备或多设备存在时停止。
- 每次运行必须获得用户明确授权；固定 single device、single session、`maxInstances=1`、`specFileRetries=0`、`connectionRetryCount=0`、Mocha retries=0。
- JUnit Reporter 是唯一结构化 TestRun 结果来源；终端输出与 Appium 日志保存，失败时必须同时保存截图和 Page Source，否则任务标记为运行错误。
- 测试项目自己的 WebdriverIO 配置负责 app capability 与测试逻辑；TestMesh 不自动安装、升级或修改目标项目。
