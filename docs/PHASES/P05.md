# P05：测试设计与用例生成

- **状态**：暂停（用户要求先完成新版需求分析；当前分析和生成型用例均为 0，P05 后续重调）
- **目标**：补齐 Requirement/Risk/Evidence → TestCase → 自动化代码 → TestRun 的可追溯闭环。

## 范围

- 选择一份既有真实分析结果，并重新上传与该分析对应的原始 PRD/截图；P05 不以领域摘要替代原文。
- 将原始 PRD 多模态内容与该分析中的 Requirement、Risk、Evidence 一起输入 OpenAI Agents SDK 运行。
- 复用 OpenAI Agents SDK 管理“覆盖规划 → 分批生成 → 缺口复核”的工具调用循环，底层仍为单一 OpenAI Responses API 模型。
- 用户人工评审并明确批准 TestCase。
- 使用 SQLite 持久化通用 TestCase，并将既有 P02 API TestCase 迁移到同一领域语义；不得保留平行模型。
- 复用 OpenHands，根据批准用例在用户选择的仓库中生成一条 Playwright 测试代码。
- 复用 P04-A 固定 Docker Runner 执行，并建立 TestCase、代码文件、TestRun 与原始证据的追溯关系。

## 第一版单一路径

```text
重新上传原始 PRD + 选择已保存的真实分析结果
  → 同一次请求读取 PRD 多模态内容及 Requirement / Risk / Evidence
  → OpenAI Agents SDK 规划覆盖并分批提交结构化 TestCase 草稿
  → 确定性工具复核来源、图片、证据与覆盖；缺口回到同一 SDK 运行继续补齐
  → 用户评审并明确批准
  → 用户授权 OpenHands 写入所选仓库
  → 用户授权 Playwright Docker 执行
  → TestRun 回链 TestCase 与原始证据
```

不维护第二个生成器、第二个代码生成 Agent 或第二个 Runner。

## TestCase 最小字段

- 标题、测试类型、测试目标。
- 前置条件、测试步骤、预期结果。
- 优先级。
- Requirement、Risk 与 Evidence 关联。
- `draft` / `approved` 评审状态。
- 自动化代码文件关联。
- TestRun 关联。

## 验收标准

1. 使用重新上传的真实 PRD 原文/图片与已保存的真实 Requirement/Risk/Evidence 共同生成结构化 TestCase 草稿；不得只改写分析摘要。
2. 每条 TestCase 至少包含 1 条证据，来源为真实需求分析结果、原始 PRD 或后续经批准接入的 RAG 命中之一；不要求三类同时存在，不得伪造来源。当前 P05 没有 RAG，只使用前两类。
3. 未经用户批准的草稿不能进入代码生成。
4. 用户授权后，OpenHands 只根据批准用例在所选仓库生成一条 Playwright 测试；TestMesh 不自研 Agent Loop。
5. 用户再次授权后，由现有 P04-A 固定 Docker Runner 执行该测试，不增加 Runner 或浏览器 fallback。
6. 工作台可从 TestRun 反查自动化代码文件、TestCase、Requirement、Risk 和 Evidence。
7. 任一固定路径失败时停在真实失败点并报告；不得以模板、mock 或第二条路径顶替。
8. 不设固定 TestCase 返回条数；数量只由真实 Evidence 支持的独立业务行为、条件、状态、输入类别和风险决定。
9. 每次生成逐一审阅所有上传来源；PDF 同时审阅正文与页面图片，独立图片审阅视觉内容，并返回可校验的视觉发现与 Evidence。
10. Requirement、每条验收标准和 Risk 均进入覆盖清单；已覆盖项回链实际 TestCase，浏览器端确实无法验证的项目以 Evidence 说明原因，任何项目不得静默遗漏。
11. Requirement、Risk 和 Evidence UUID 均只能来自所选分析；单条用例可只引用需求分析证据或只引用 PRD Evidence，但三类证据合计不能为 0，不额外要求沿用分析阶段的关联组合。

## 明确不做

- 自研 Agent Loop、工作流运行时、自动评审或自动批准；本阶段复用官方 OpenAI Agents SDK。
- 未经用户授权写代码、执行测试、commit 或 push。
- 多模型、多生成器、备用 Runner 或 silent fallback。
- API、APP、性能或安全测试代码生成；P05 第一版只验收 Playwright 单一路径。
- P06 的知识检索、Failure Triage、Quality Gate、完整回归与 CI。
