# 异常与跨系统测试

## 识别交接点

- 用户端 ↔ Agent/应用
- Agent ↔ 订单、物流、支付、仓储、客服、知识库等外部系统
- 同步请求 ↔ 异步消息/任务
- 业务状态 ↔ 数据库、缓存、消息和第三方结果
- 普通用户 ↔ 客服、商家、审核或管理员

## 每个有证据的交接点检查

1. 成功结果与状态同步。
2. 超时、明确失败、返回空值或格式错误。
3. 重复提交、重放、并发请求和幂等保护。
4. 部分成功、补偿、回滚或人工接管。
5. 权限不足、敏感数据越权或脱敏。
6. 上下游状态不一致、消息延迟/重复/乱序。
7. 失败后的用户可见提示、工单、审计和重试边界。

只生成 PRD、基线或 RAG 证据能够支持的预期结果。若异常处理未定义，应设计“不得静默成功/不得执行不可逆动作/进入待确认或人工处理”的保护性测试，并把缺口追溯到对应 open question；不得自行规定重试次数、超时时间或补偿算法。
