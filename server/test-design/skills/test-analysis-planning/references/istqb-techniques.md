# ISTQB 测试分析与设计参考

依据 ISTQB CTFL 4.0.1 第 4 章，仅保留生成时需要执行的覆盖准则：

- 等价类：先识别互斥且非空的有效/无效分区；每个已识别分区至少由一个测试覆盖。
- 边界值：只对有序分区使用；覆盖明确边界以及所选 2-value/3-value 方法要求的相邻值。
- 判定表：列出条件、取值、动作和不可行组合；测试覆盖每条可行且业务不同的规则。
- 状态迁移：识别状态、事件、守卫和动作；覆盖要求的有效迁移，并为规范明确禁止或需要保护的无效迁移设计测试。
- 场景/用例：覆盖主成功路径、替代路径和异常路径；跨角色或外部系统的交接点必须有可观察结果。
- 经验型补充：错误猜测只能补充规范型技法，不能替代基线追溯。
